## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Karan-desai-7299/karansinh-portfolio.git
```

Move into the project

```bash
cd karansinh-portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
